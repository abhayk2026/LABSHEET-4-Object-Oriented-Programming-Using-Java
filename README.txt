MCA III Semester - Lab Sheet 04
Object Oriented Programming Using Java

This folder contains 15 independent Java programs matching the uploaded Lab Sheet-04.

IMPORTANT:
- Each .java file is a separate program.
- Keep each file name unchanged because the public class name matches the file name.
- JDK must be installed to compile and run Java programs.

How to compile and run one program:
1. Open Command Prompt or Terminal in this folder.
2. Compile, for example:
   javac Q01_StudentRecord.java
3. Run:
   java Q01_StudentRecord

For another program, replace the file/class name with the desired question number.
Example:
   javac Q14_ShapeHierarchy.java
   java Q14_ShapeHierarchy

Questions 12 and 13 are conceptual-only, as requested by the lab sheet.
Question 15 is the integrated final hospital staff application.
